## Per-band echo time in a room that is boomier in the bass

True RT60: 1.1 s at 500 Hz, 0.8 s at 1 kHz, 0.6 s at 2 kHz, 0.45 s at 4 kHz; clap 55 dB above noise.

| Band | Mean error | Worst |
| --- | --- | --- |
| 500 Hz | 2.9 % | 6.7 % |
| 1 kHz | 7.8 % | 18.1 % |
| 2 kHz | 5.1 % | 11.4 % |
| 4 kHz | 3.9 % | 11.1 % |

The higher bands read slightly long here because some of the longer bass decay leaks through the octave filters;
real octave-band meters have the same effect.

## What this does not show

These rooms are ideal diffuse fields. Real rooms have early reflections, flutter echoes between parallel walls and
decays that bend; a hand clap is not perfectly loud at every frequency; and phone microphones may filter the sound.
So treat a real-room reading as good to roughly ±10-20 %, which is enough to tell "dry" from "echoey" and to see
whether a change helped, but it is not a certified ISO 3382 measurement.
